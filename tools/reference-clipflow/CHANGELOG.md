# 变更说明：从 v0.3.0/v0.4.0 的音频ASR模式回撤到 v0.5.0 纯视觉字幕模式

- 已移除 faster-whisper 依赖声明、`clipflow transcribe` 音频转写命令及 ASR 自动执行代码。
- 新增 `clipflow.visual_ocr`，使用本地 Tesseract / 中文语言包扫描原视频画面可见字幕；按稳定帧合并并去重。
- 固定每次输出 `segments_transcript.md`：每一个编号视频对应一段台词和一次分秒起止时间。
- 没有可见字幕仍交付 MD 和编号 MP4 ZIP；不生成伪造台词或空白 SRT。
- 旧 ASR 一键包不再作为现行入口；新的发行包不包含 ASR 代码、模型下载脚本或网络服务。
- 原有水印 C、片段拼接、去灰通透调色、可选原声/字幕和不默认60帧均保留。

注意：这是一份新发行包，不会自动在用户其他电脑上卸载曾经单独安装的第三方 Whisper 库。它只保证新包本身不会安装或调用它们。
