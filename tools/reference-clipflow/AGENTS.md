# Reference ClipFlow｜纯画面字幕 OCR 执行规则 v0.5.0

## 最高优先级

用户已要求回撤音频转写：不下载、不安装、不调用 ASR、Whisper、faster-whisper、云端音频文字 API；不依据视频音轨猜台词。**只根据原视频画面中真正看得见的字幕执行 OCR**，而非把无字幕的视频描述成已有文案。

## 对标视频默认执行

1. 检查当前环境已有 ClipFlow、FFmpeg、Tesseract 与中文语言包，能复用就直接复用。
2. 以镜头/画面变化和可见字幕切换辅助，按最长小于或等于 10 秒切分；保持源视频原画面、原声与帧率。原声音轨只是保留在导出的 MP4 中，不参与文字识别。
3. C 方案编号水印从 001 开始，左上灰白大号（白色透明度 40%，黑描边 80%，1920 横屏描边 10px、1080 竖屏描边 7px）。
4. 对原视频（未加编号水印）抽帧并调用 Tesseract OCR。OCR 字样必须满足可信度和跨帧稳定性，不把背景图案、人物面部或水印误识别当台词；保留原帧以供核查。
5. **每次固定导出 `segments_transcript.md`**。整个文件按视频顺序一段一块，每块只有一次原视频起止时间（分秒）和该段全部画面字幕台词。不增加逐句时间戳。逐段文字同时记录在 `manifest.json` 中。
6. 若整段或整片没有可识别的可见画面字幕，对应位置写“（本段未检测到可识别画面字幕；口播内容未知）”，不能编造，也不能暗中回退音频识别。无可用OCR字幕时不伪造 `captions.srt`。
7. 导出 `numbered_segments.zip`、`manifest.json`、`segments_transcript.md`、原视频字幕样张和样式配置包。可用可见字幕时生成 `captions.srt`。
8. 如未装 Tesseract/中文 OCR 数据，应提示需配置的**图像文字识别工具**，不得自动转回音频识别。

## 新片段默认执行

自动排序、完整拼接、去灰通透近似调色；原声替换、字幕压制仅用户明确要求才启用。不默认做60fps或AI补帧。没有可靠序号/顺序时不得乱猜。

## 字幕合成外观

明确要求字幕合成时，先依据原视频参考截图检查字体字形、尺寸、字重、字距、颜色/高亮、描边、阴影、水平垂直位置与显示节奏。参考有字幕时尽量还原；无字幕且已核查时使用后备样式；未核查时不可擅自回退固定B/C风格。

## 真实验收

- MD 片段编号与 ZIP 的 MP4 一一对应；每段时间范围准确；无逐句时间戳。
- OCR 来源标识为 `visual_ocr`；未提取到文字用 `none_visible`；用户提供 SRT 用 `supplied_srt`。
- 无可信可见字幕不得称“已经取得完整口播文案”。自动OCR仍需要人工核对。
- GitHub 不上传用户视频、音轨、字体或私有密钥；版本更新和执行情况必须与实际文件一致。
