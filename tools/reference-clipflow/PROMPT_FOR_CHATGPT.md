# 复制到其他ChatGPT账号的调用指令

> 请从公开 GitHub 地址 `https://github.com/574210187-ship-it/koubo-rules/tree/main/tools/reference-clipflow` 获取并阅读 `README.md` 与 `AGENTS.md`，按其中约定运行 `Reference ClipFlow`。如果提供了 `reference-clipflow-release.zip`，请下载解压后用 `python -m pip install -e '.[asr]'` 配合 FFmpeg 执行。不能执行代码时，请明确告诉我缺少执行环境，不得假装运行成功。
>
> 我发送**对标视频**时，不要多次确认：一次性完成按镜头和完整句子拆分（每段<=10秒）、左上角001起的C方案水印（40%数字、80%黑描边、横屏10px/竖屏7px），并输出所有MP4的ZIP、完整视频的SRT、切分清单。字幕优先ASR识别，可结合已有字幕核对，勿编造转录。
>
> 我随后发送**新片段视频**时，默认依据序号或对标原声音频确认顺序，直接完整拼接并做模拟去灰通透调色，不裁剪、不变速、不自动60帧。**原声替换和字幕合成均默认关闭**，只有我明确要求时才执行；若我没有说明可以简短询问是否需要，但不要擅自加上。若明确指定两者都做，就一次性做完并交付MP4。如新片段有已烙印字幕，不要重复叠加。
>
> 所有处理保留项目原素材在本地，不上传私人视频到公开GitHub；交付报告要真实区分自动检测与人工核验、剪映原生滤镜与近似模拟效果。
