# 实况视频单窗口｜跨账号及多端同步合同（v1.0.2-public-candidate）

公开 GitHub 主来源：https://github.com/574210187-ship-it/koubo-rules/tree/shikuang-public-v1.0.2/projects/shikuang-singlewindow。Space 是本账号版本归档，COS 当前仅连接表情素材专用库，不具备通用 ZIP 上传接口。

## 当前公开策略
- 公开仓库只在 `shikuang-public-v1.0.2` 分支的 `projects/shikuang-singlewindow/` 发布本工具，不暴露私有 `personal-ai-starter` 的内容，不改 `koubo-rules/main`。
- 当前ZIP候选版，可下载、检查源码、在有相关执行权限的平台试运行；不把可下载误称跨账号 ImageGen/FFmpeg 安装成功。
- 每个新版本独立ZIP与SHA256SUMS，不原位覆盖历史包。GitHub/Space/COS 独立回读哈希，未成功的一端标记 BLOCKED。
- 源码由当前工具提供，在新账号可阅读 `START_HERE.md`。使用本轮原始素材，00→01→02→03按已冻结业务规则逐步执行。AUTO也不得跳过QA。
- 不上传用户原视频、文字图、成品MP4、OAuth或凭据到公开仓库。真实成片和任务state仅存在受授权的执行空间。

## 未来同步方式
1. 发布前执行单测、ZIP成员签名、敏感信息扫描、重新计算SHA256。
2. 使用 `tools/sync_publish.py` 或GitHub连接提交同版本到当前公开仓库发布分支，并读回比较SHA256。
3. 使用ChatGPT Files把原ZIP归档到 `/实况/单窗口/releases/<version>/` 并读回核对；COS如果已接入独立通用读写接口，再上传并回读。
4. 写同版 `SYNC_RECEIPT.json`；失败目标不是 PASS，保留可继续的任务状态。发布不是常驻后台任务，不保证未来不调用工具就自动同步。
