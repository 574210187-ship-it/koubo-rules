# 实况视频单窗口 · 00 素材与文字分析 · v0.2.0

## 业务目的
唯一主画面来自用户上传的 **主视频**。参考来源为 **一张对标图片** 或 **一条对标视频**，只负责提供文字及排版样式。不得把参考画面当作新主视频，不得调用旧项目的视频「第3秒显字」规则。

本轮启动指令、同时附加的改字要求、主视频、对标素材，一起进入 00。启动时已有改字要求必须先应用到 `final_text`，再进行 01 生图；不能把改字要求挪到视频完成后执行。

## 第一步：只读采样、事实锁定
1. 原样锁定用户上传主视频和对标文件的路径、字节长度、SHA-256。主视频必须可解码，有视频流。参考图片支持 PNG/JPEG/WEBP，参考视频支持 MP4/MOV/MKV/WEBM。
2. 对主视频做必要帧采样，记录画面比例、关键动作、可安全截取的连续区间及可能的原画面内文字、遮挡；不擅自改动主画面、速度、方向。
3. 对标是图片：阅读完整可见文字并记录每段的实际位置、行距、换行、字体粗细、色彩、层级、可读性。
4. 对标是视频：抽取多个关键时点，收集全部文字变化；识别其是否本来就有多页、滚动、转场或其他动画，但**这些动画只用于理解原文，不许迁移到最终视频**。确定一套全程静止、完整且可读的文字布局。若原对标有几套无法同时容纳的正文，停止请用户明确保留哪套，不能擅自截断。
5. 视频素材是否含音轨必须通过媒体检查，不从参考视频取音轨；仅截取主视频音轨（主视频无声则静音）。
6. 视频时长：用户已定案 **默认从原视频截取，不变速、不加速、不减速**。默认主片从 0 秒起截取最多约 2.9 秒；允许用户提出主视频内的其他起点。若主视频不足 2.9 秒，截取实际可用片段，不循环、不补帧拉长、不改速。任一输出必须严格 <3.0s。

## 第二步：文字语义政策
- `reference_text`：记录对标原文；`final_text`：应用本轮所有合法明确的用户改字要求后的最终全文。保存完整改动说明 `user_edits` 或 `text_transform_notes`。不能杜撰、悄悄改写具体数字、日期、事实、法律结论或来源。
- 参照姜律师项目的品牌处理：只有**原律师署名或称呼**统一为“盐城姜律师”；移除原律师的城市/律所/职务/认证/个人品牌/水印，不转嫁个人经历。对标正常叙事中的普通职业词“律师”、其他人物或机构不能机械全部替换。用户指定的新文案优先检查事实与语义。不得使用原律师照片冒充姜律师。
- 文字内容、数字、顺序和逻辑尽量与对标一致，原则上不增删改写，除用户明确修改与上述品牌规范；如果需要收缩字数才能在 2.9 秒内看清，先报告读不清/空间不足并停止，不可擅自删字。

## 第三步：00证据、路由与确认
1. 命令 `python src/prepare_00.py --main ... --reference ... --out ... [--edit ...]` 只能生成**技术草稿**，不会自动阅读、OCR 或理解素材；需要执行者实际观看后填入 00 结果。空的语义字段不得登记通过。
2. 00 至少需要：`facts.input_kind`、素材路径、`reference_text`、`final_text`、`layout_evidence`、`reference_layout_kind`、`user_edits`、时间起点/时长、静态政策字段与 `evidence`。
3. 唯一主分支：
   - `main_video+reference_image` → `STATIC_REF_IMAGE`
   - `main_video+reference_video` → `STATIC_REF_VIDEO`
4. 严格政策：`text_mode=STATIC_FULL_DURATION`、`playback=ORIGINAL_SPEED_TRIM`、`effects=NONE`、`speed_factor=1`、`text_start_seconds=0`、`0<clip_duration_seconds<3`。
5. REVIEW：展示完整对标文字、拟用终稿、布局说明、素材角色/时长，等待用户确认 00。AUTO：只有真实内容分析和 QA 完成才继续，不是省略分析。

**禁止**：从用户未提供的视频臆造画面、伪造阅读结果、将动态/滚动文字迁移到成片、拿旧项目 VIDEO_MAIN 引擎偷换。
