# 实况视频单窗口 v0.2.0 变更记录

基线：`v0.1.0` 原启动ZIP，保留于 `legacy/`，不覆盖原文件。

1. 根据 2026-10-25 用户确认：**原速连续截取；文字全程静止、无滚动无动效**，默认 2.9 秒、严格小于 3 秒。
2. 新增主视频＋对标图片及主视频＋对标视频两条唯一分支；00可接收启动时改字指令，需真实视觉分析再批准。
3. 01仅 ImageGen RGBA 生字图；程序只读验证透明度、纵横比、来源记录和 SHA。02 使用静态叠加候选视频 ZIP；03验收视频/封装时长、音视频、哈希、视觉 QA。
4. 保持状态/返工/REVIEW/AUTO/锁定源版本。新分支技术测试通过，但正式引擎候选状态未批准，不把合成 MP4 当用户真实成片。
5. 新增测试10项，总计25项；发布包新版本自校验与 SHA 清单。
