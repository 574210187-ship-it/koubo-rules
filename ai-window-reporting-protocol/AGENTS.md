# Agent instructions

1. Read `START.md` completely before reporting any task result or problem.
2. The launch instruction must provide the target Feishu Bitable. Never guess or persist a target from another conversation.
3. One window run or one problem equals one newly appended row.
4. Never append a new report to an old row or combine multiple reports in one cell.
5. Use the result or problem template exactly, validate it, write it, then read it back.
6. Do not claim success without a returned and verified Feishu `record_id`.
7. Never commit credentials, OAuth tokens, Webhook keys, cookies, or private target URLs to this public repository.
